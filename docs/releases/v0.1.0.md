# v0.1.0 Release Notes

## Summary

First release of `canondocs`, a small command-line tool that writes RFC 8785
(JCS) canonical JSON bytes, `sha256:` digests and golden vector records from
JSON, YAML 1.2 Core or NDJSON input. It is a single static binary with no
runtime dependencies, makes no network calls, and keeps no state.

## Highlights

- `canondocs jcs [file|-]` writes canonical bytes with no trailing newline;
  `--check` exits 0 only if JSON input is already canonical, `--digest` writes
  `sha256:<hex>`, and `--vector` writes a canonical vector record.
- Input format from the file suffix or `--from auto|json|yaml|ndjson`. YAML is
  projected to I-JSON by six fail-closed rules (`yaml/jcs-rfc8785-v0`); unknown
  tags are refused, and `<<` merge keys are refused unless
  `--allow-merge-keys` is given.
- `--ndjson-array [--head N]` canonicalizes a strict LF-terminated NDJSON
  prefix as one array; `--sort-set` treats an array as a set, sorted by
  element canonical bytes, with duplicates refused.
- Input limits: `--max-bytes`, `--max-depth`, `--max-object-members` and
  `--max-string-bytes`, with fixed defaults.
- `canondocs info` describes the scheme as canonical JSON, `canondocs version
  [--json]` prints the version, and `canondocs doctor` runs a built-in
  self-check.
- Binaries for darwin-arm64, linux-amd64, linux-arm64, windows-amd64 and
  windows-arm64.

## Release provenance

- Before importing a downloaded public key, establish the expected GPG signing
  key and minisign public-key fingerprint through an independently trusted
  maintainer channel. Follow the complete
  [release-verification guide](https://github.com/3leaps/canondocs/blob/v0.1.0/docs/security/README.md).
- Release tags are GPG-signed. After validating the public material against
  the committed anchors, verify with `git tag -v v0.1.0`.
- Checksum manifests are signed with minisign and PGP; the published assets are
  byte-identical to the signed set.

## Install

```bash
brew install 3leaps/tap/canondocs                      # macOS Apple Silicon, Linux
go install github.com/3leaps/canondocs/cmd/canondocs@v0.1.0
```

```powershell
scoop bucket add 3leaps https://github.com/3leaps/scoop-bucket
scoop install canondocs
```

## Verification

`canondocs` canonicalizes and digests; it verifies no signatures, so it embeds
no key. To verify this release, check the signed tag `v0.1.0` and the signed
checksum manifests (`SHA256SUMS`, `SHA512SUMS`) against the public pins
committed in the tagged commit (`docs/security/`, `keys/`); see the
release-verification guide above.
