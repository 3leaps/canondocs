# v0.1.1 Release Notes

## Summary

Maintenance release. `canondocs` now builds against
`github.com/3leaps/yamlprims` v0.2.1. Command-line behavior and canonical
output are unchanged from v0.1.0. The maintainer release tooling binds the
CI-artifact download more tightly to the signed tag.

## Changes

- `github.com/3leaps/yamlprims` v0.1.1 to v0.2.1. The YAML loading path
  `canondocs` uses behaves the same: canonical bytes, digests, vectors,
  refusals and exit codes are unchanged.
- Release tooling (maintainers only; nothing in the published binaries):
  - The CI-artifact download requires the ceremony anchor recorded when the
    tag was published. The anchor must sit at an absolute path outside the
    repository with no symlink, and must match the verified tag, object and
    commit byte for byte.
  - Without a named run, the download selects the single successful
    push-triggered release workflow run for the tag at the tagged commit. It
    refuses ambiguous or incomplete run listings. Only the
    `CANONDOCS_RELEASE_RUN_ID` and `CANONDOCS_RELEASE_RUN_ATTEMPT` selectors
    are read; unprefixed `RELEASE_RUN_ID` or `RELEASE_RUN_ATTEMPT` is refused.
  - The release checklist describes the accepted Homebrew formula shape, and
    the tag-protection check documents its three tag patterns.

## Release provenance

- Before importing a downloaded public key, establish the expected GPG signing
  key and minisign public-key fingerprint through an independently trusted
  maintainer channel. Follow the complete
  [release-verification guide](https://github.com/3leaps/canondocs/blob/v0.1.1/docs/security/README.md).
- Release tags are GPG-signed. After validating the public material against
  the committed anchors, verify with `git tag -v v0.1.1`.
- Checksum manifests are signed with minisign and PGP; the published assets are
  byte-identical to the signed set.

## Install

```bash
brew install 3leaps/tap/canondocs                      # macOS Apple Silicon, Linux
go install github.com/3leaps/canondocs/cmd/canondocs@v0.1.1
```

```powershell
scoop bucket add 3leaps https://github.com/3leaps/scoop-bucket
scoop install canondocs
```

## Verification

`canondocs` canonicalizes and digests; it verifies no signatures, so it embeds
no key. To verify this release, check the signed tag `v0.1.1` and the signed
checksum manifests (`SHA256SUMS`, `SHA512SUMS`) against the public pins
committed in the tagged commit (`docs/security/`, `keys/`); see the
release-verification guide above.
